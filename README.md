# Water Quality Checker & Contamination Predictor

This project is an interactive, browser-based dashboard designed to help identify early signs of possible water contamination using simple, transparent indicators. The tool analyzes pH, turbidity, conductivity, and rainfall to estimate contamination risk across different water sites in Kenya. It provides visual trends, risk summaries, and exportable datasets without requiring any backend server or special installation.

## 🌍 Project Purpose

I created this project to explore how computer science can be applied to public health and environmental safety. Water contamination remains a major challenge in many regions, and this tool demonstrates how simple analytical methods can help communities understand risk patterns in a clear and accessible way.

The entire dashboard runs in the browser, making it lightweight and usable even in low-resource settings.

---

## ✨ Features

- Upload CSV files with water-quality data  
- Built-in synthetic demo dataset  
- Interactive charts for pH, turbidity, conductivity, and rainfall  
- A transparent rule-based contamination risk score  
- Alerts for high-risk periods  
- CSV export of filtered data  
- No backend required — fully client-side  

---

## 📊 Data Format (CSV)

Your CSV file should follow this structure:- `site`: name of water source  
- `month`: YYYY-MM format  
- `pH`: numeric  
- `turbidity`: NTU  
- `conductivity`: µS/cm  
- `rainfall`: mm
